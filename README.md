# Sales Performance & Customer Behavior Analysis

This project performs end-to-end data analysis on multi-source sales data.

## Steps Performed
- Created multiple independent sales datasets to simulate real-world data         sources
- Merged datasets and handled duplicate orders
- Cleaned missing values, inconsistent categories, regions, and mixed date        formats
- Performed feature engineering (discount normalization, revenue calculation)
- Conducted Exploratory Data Analysis (EDA)
- Generated business insights using visualizations

## Steps Performed
- Data merging from multiple sources
- Data cleaning (missing values, duplicates, inconsistent categories, mixed date formats)
- Feature engineering (revenue calculation)
- Exploratory Data Analysis (EDA)
- Business insights and visualizations

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights
- Technology products (especially Laptops) generate the highest revenue
- South region contributes the maximum sales
- Moderate discounts yield better revenue than extreme discounts
- Seasonal patterns observed across months
